# Security Policy

## Supported Versions

We actively maintain and provide security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of `@modelnorth/dsh-plugin-memory` and our community very seriously.

If you believe you have found a security vulnerability in this repository:

1. **Do not disclose the vulnerability publicly** in issues, discussions, or pull requests.
2. Please report the issue privately by opening a [Security Advisory](https://github.com/menotbobbybrown/dsh-plugin-memory/security/advisories/new) on GitHub.
3. Include detailed steps to reproduce the vulnerability, proof-of-concept payloads, and affected versions.

We will acknowledge receipt of your vulnerability report within 24 hours, validate the issue, and release a coordinated patch promptly.
